# 🏛️ SchemeSathi AI

### Government Schemes Made Simple, For Everyone.

SchemeSathi AI is an AI-powered multilingual government schemes assistant that helps citizens understand Indian government schemes, eligibility criteria, required documents, and application procedures in simple language.

## 🎯 Problem Statement

Many citizens struggle to understand government schemes because information is complex, scattered across websites, and often unavailable in their preferred language.

## 💡 Our Solution

SchemeSathi AI makes government scheme information easier to understand through an AI-powered multilingual assistant.

## ✨ Key Features

- 🌐 Multilingual support – Marathi, Hindi, and English
- 🤖 AI-powered question answering using Groq API
- 📋 Scheme eligibility guidance
- 📄 Required document information
- 📝 Application process guidance
- 🏛️ Information about multiple government schemes
- 🔍 Scheme information retrieval from available documents

## 🛠️ Technology Stack

- Python
- Streamlit
- Groq API
- OpenAI GPT-OSS 20B Model
- PyPDF
- Python-based document retrieval

## 🚀 How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/prachisonone04-ui/SchemeSathi-AI-Repository.git
   ```

2. Open the project folder:

   ```bash
   cd SchemeSathi-AI-Repository
   ```

3. Create a virtual environment:

   ```bash
   python -m venv venv
   ```

4. Activate it on Windows:

   ```powershell
   .\venv\Scripts\Activate.ps1
   ```

5. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

6. Create a `.env` file and add your Groq API key:

   ```env
   GROQ_API_KEY=your_groq_api_key_here
   ```

7. Start the application:

   ```bash
   streamlit run app.py
   ```
